# SpeakFirst

An always-on desktop AI tutor and notebook for language learners.

## Features

- AI chat with OpenRouter or local Ollama/OpenAI-compatible models
- Nested chat threads and markdown notebooks
- Screen-region capture for asking about videos, PDFs, or apps
- Always-on-top floating launcher
- Flashcard creation with Anki-importable TSV export
- Light, dark, and system themes

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Check Types

```bash
npm run typecheck
```
